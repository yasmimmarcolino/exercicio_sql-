# Exercício de SQL

**Autora:** Yasmim Ferreira Marcolino

Este repositório reúne oito consultas SQL para praticar a busca e a organização de informações em um banco de dados de vendas.

As consultas estão no arquivo [exercico.sql](exercico.sql) e abordam:

- Produtos, lojas e comissões por categoria;
- Produtos com preço abaixo de R$ 100;
- Pedidos entregues e clientes sem pedidos;
- Quantidade de pedidos por status e valor total de cada pedido;
- Faturamento das lojas e comissão da plataforma nas vendas entregues.

Para executar, abra o arquivo no editor SQL conectado ao banco do exercício e rode as consultas. As tabelas e os dados precisam estar criados antes.
